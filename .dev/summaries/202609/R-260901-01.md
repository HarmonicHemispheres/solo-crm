## Decisions

- `editSheet(kind, id, trigger?)` is a second method on the layer manager,
  not an optional id on `openSheet` — the create and edit call shapes cannot
  be confused (T-260901-10, recorded in `layer-manager-context.ts`).
- `InfoPopover` registers with the layer stack rather than owning its own
  Escape; standalone mounts keep a local Escape (T-260901-06).
- The branding picker was generalised by extraction, not copied:
  `electron/main/images/picker.ts` owns the dialog, the in-flight guard and
  the bounded read, and `branding/picker.ts` is a thin adapter over it
  (T-260901-12). One refusal behaviour for both consumers.
- The Offerings view has no `view.offerings.mode` setting — it is one
  layout, so a persisted mode would be a key with one value (T-260901-11).
- On the engagement edit form the offering picker stays editable but the
  rate does not: re-pointing a signed engagement keeps its agreed rate, the
  options show no prices, and `agreedRateCents` is never in an update
  payload (T-260901-13, ADR-003).
- Engagement list and get reads join through to the offering *name* only;
  no rate column is selected, so the renderer cannot display a live price
  (T-260901-13).

## What went wrong

- **Node.** The machine's system Node 22.12.0 segfaults `better-sqlite3`; every
  check in this run ran on a scratchpad Node 22.22.0 prepended to `PATH`, and
  `npm run <script>` exited 1 silently under it, so the gates were invoked as
  `node node_modules/typescript/lib/tsc.js`, `node node_modules/eslint/bin/eslint.js`
  and `node node_modules/vitest/vitest.mjs` directly. Same tools, same
  configs — but not the `npm run verify` string the task files name.
- **T-260901-05's overlap tests could not fail on the boundary.** Two mutants
  (`<=` → `<` on either side of `assertNoOverlappingVersion`) survived because
  the same-day refusal was asserted after an abutting open-ended version
  already existed. Fixed on the branch before merge; the outcome records it.
- **Cross-branch break at T-260901-10's merge.** T-06's `InfoPopover.test.tsx`
  fakes the layer context; T-10 widened the context. Green alone, red
  together; fixed on main in `639aa2e`. This is the case the end-of-wave gate
  exists for — it surfaced at the per-merge check instead, which is earlier.
- **A second T-10 leftover surfaced at T-08's merge.** The integration
  project (`tsconfig.integration.json`) still mounted `EngagementSheet`
  without the `target` prop T-10 made required. My T-10 merge check ran
  `tsconfig.web` only; from T-08 on, every merge runs all three projects.
  Fixed on main in `9b08666`.
- **Builders' "lint clean" is not evidence under the Node workaround.**
  T-07's branch reported eslint clean; the merged tree failed
  `local/no-literal-colour` on a stub fixture. `npm run lint` exits 1
  silently on the scratchpad Node, so a builder cannot tell a pass from a
  non-run. Every lint claim in this run was re-run at merge as
  `node node_modules/eslint/bin/eslint.js`.
- **Two T-260901-08 mutants survived** — the byte-cap boundary and
  `updated_at` on a replacement — and were strengthened on the branch before
  merge. A third "survivor" was the harness: `String.replace` hit an SQL
  comment's `ON DELETE cascade` before the constraint's. Files here are CRLF,
  so multi-line mutants report "no match"; single-line, first-occurrence
  checked with grep, is the working form.
- **Three wave-3 mutants survived, one per task.** T-12: `canceled: true`
  with a path riding along was never exercised, so the flag could be ignored
  and the file stat'd. T-11: the archived list's category predicate only
  matters under a category filter, which no test applied. T-13: the
  `{ active: true }` filter on the picker's list read could become `{}`
  unnoticed, because the stub returned the same rows either way — the
  filter is the whole defence against selling an archived offering. Each
  got a test at merge; none was a defect in the shipped code.
- T-260901-01, 02, 09, 11 and 13 are renderer changes verified by tests and
  by reading the diff, not by eyeballing the running Electron app. T-09's
  900px and reduced-motion criteria in particular are read off the
  stylesheet.
