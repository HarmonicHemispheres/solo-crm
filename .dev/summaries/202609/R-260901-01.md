## Decisions

- `editSheet(kind, id, trigger?)` is a second method on the layer manager,
  not an optional id on `openSheet` — the create and edit call shapes cannot
  be confused (T-260901-10, recorded in `layer-manager-context.ts`).
- `InfoPopover` registers with the layer stack rather than owning its own
  Escape; standalone mounts keep a local Escape (T-260901-06).
